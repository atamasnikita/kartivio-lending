# Wordstat Conversion Opportunities, 2026-09-10

Scope:
- Source: Yandex Search API Wordstat
- Region: `225` Russia
- Device: `DEVICE_ALL`
- Goal: find low/mid-frequency article ideas that can convert into registration, bot start, or paid generation
- API key was passed through `YANDEX_SEARCH_API_KEY` and is not stored in the repo

## Main Takeaways

The best conversion opportunities are not always the largest generic clusters. The highest-fit clusters for Kartivio are where the user already wants a concrete output from their own photo:

- avatar / profile photo
- birthday AI photoshoot
- portrait from photo
- studio photo from photo
- family / couple photoshoot
- pregnancy / wedding as emotional paid-use cases
- MAX avatar as a channel-specific opportunity

Avoid importing `associations` directly. They are often noisy and sometimes unsafe. Use them only as hints for new seed phrases.
